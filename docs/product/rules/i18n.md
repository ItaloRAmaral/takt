# Regras de idiomas

> **Resumo.** A interface existe em português do Brasil (padrão) e inglês. O que o usuário cria não é traduzido, e o JSON da planta não depende de idioma.

Atualizado em 19/10/2026 · Origem: [PDR-0016](../../pdr/0016-idiomas.md).

### RN-I18-001: Idioma inicial e preferência

- **Enunciado:** na primeira visita, o idioma vem do navegador (português se não for português nem inglês). Depois que o usuário escolhe, a preferência fica salva no perfil e prevalece.
- **Origem:** PDR-0016.
- **Exemplo:** um navegador em espanhol abre o Takt em português.
- **Quando violada:** não se aplica.

### RN-I18-002: Conteúdo do usuário não é traduzido

- **Enunciado:** nomes e textos criados pelo usuário aparecem como foram escritos, em qualquer idioma da interface. Nomes padrão ("Estação 1") nascem no idioma de quem cria.
- **Origem:** PDR-0016.
- **Exemplo:** a planta "Linha de envase", aberta por alguém com a interface em inglês, continua "Linha de envase".
- **Quando violada:** não se aplica.

### RN-I18-003: JSON independente de idioma

- **Enunciado:** o JSON da planta usa ponto decimal e as unidades fixas do esquema, qualquer que seja o idioma.
- **Origem:** PDR-0016.
- **Exemplo:** uma taxa de defeitos exibida como "0,02" na interface em português é gravada como `0.02`.
- **Quando violada:** `INVALID_PLANT_FILE`.

### RN-I18-004: API devolve códigos

- **Enunciado:** a API responde erros e avisos com códigos (por exemplo, `PLAN_LIMIT`), nunca com frases. A interface traduz.
- **Origem:** PDR-0016.
- **Exemplo:** o mesmo `FORBIDDEN` aparece como "Você não tem permissão" ou "You don't have permission".
- **Quando violada:** não se aplica.
