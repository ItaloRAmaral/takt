## Contexto

O portfólio se beneficia de código visível; a venda futura de assinaturas, de código fechado. Com código aberto, qualquer pessoa pode copiar o produto.

## Decisão

O repositório é **privado**. Só o **produto** fica visível (demo público e vídeos).

## Alternativas consideradas

- **Público com licença AGPL:** protege parcialmente o uso comercial, mas expõe tudo.
- **Núcleo privado com partes abertas** (por exemplo, o motor como biblioteca): fica como possibilidade futura.

## Consequências

- O recrutador não vê o código. **Palpite:** ADRs públicos e posts técnicos com trechos compensam.
- **Em aberto:** como mostrar o código no portfólio.

Nenhuma.
